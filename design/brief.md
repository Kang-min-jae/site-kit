# brief.md — 사이트 요청 양식

> "이 사이트를 이런 느낌으로 만들어줘"를 이 양식으로 보내면 된다. **★ 칸만 채워도 시작할 수 있다.**
> v0.2: 보여주는 사이트는 10~12칸(디렉션 · 시그니처 장면 · 소재 상태)을 채우면 결과가 훨씬 구체적이 된다.
> 풀스택 키트의 `SITE_REQUEST.md`(v3)와 **칸 번호가 같다**. 9번(기능)은 SITE_REQUEST에서 F1~F14로 펼쳐 쓴다. 이 파일을 바꾸면 SITE_REQUEST의 디자인 칸도 함께 바꾼다.
> 빈 칸은 DESIGN.md 기본값으로 채우고, 무엇으로 채웠는지 결과 맨 위에 적는다.

```markdown
## 사이트 요청

1. ★ 목적 (한 문장: 누가, 여기서 무엇을 하나)
   예) 동네 필라테스 스튜디오의 수업을 보고 바로 예약하는 사이트

2. ★ 주 사용자 (누구, 어떤 기기)
   예) 20~40대 직장인, 대부분 모바일

3. ★ 첫 화면에서 할 행동 하나
   예) 이번 주 수업 시간표 보고 예약하기

4. 필요한 페이지 (아는 만큼)
   예) 홈 / 수업 목록 / 수업 상세 / 예약(3단계) / 로그인·가입 / 마이페이지

5. ★ 느꼈으면 하는 단어 3개
   예) 차분한 · 깨끗한 · 따뜻한

6. 이런 느낌은 싫다 (선택)
   예) 헬스장 같은 강렬한 색, 동기부여 문구

7. 참고한 느낌 (선택 — 링크 또는 "R4 같은 카드 탐색"처럼 프로필 번호)
   ※ 원리만 참고한다. 색·이미지·문구·배치를 옮기지 않는다.

8. 이미 정해진 것 (선택)
   이름/로고 파일, 강조색, 사진 보유 여부, 꼭 들어갈 문구

9. 기능 (풀스택 플레이북과 연결)
   로그인 방식, 결제 여부, 관리자 화면, 알림 메일 등

10. 디렉션 (v0.2 — 보여주는 사이트면)
   house / editorial / object / 없음(프리셋만) — 모르면 비워 두면 AI가 directions.md 0장으로 고른다

11. 시그니처 장면 한 줄 (선택 — 이 사이트를 기억하게 할 장면 하나)
   예) 정물 사진이 화면 아래에서 천천히 드러난다

12. 소재 상태
   사진/영상/3D가 있나 (있음 · 촬영 예정 · 없음) — 없으면 시안은 직접 렌더한 소재로 채운다
```

## 작성 예시

```markdown
1. 독립 출판 책을 소개하고 온라인으로 파는 작은 서점
2. 책 좋아하는 20~30대, PC와 모바일 반반
3. 이번 달 들어온 책 둘러보고 장바구니 담기
4. 홈 / 책 목록(분류·정렬) / 책 상세 / 장바구니·결제 / 글(서점 일기) / 로그인
5. 조용한 · 잡지 같은 · 따뜻한
6. 대형 서점처럼 빽빽한 화면, 할인 배너
7. R12 같은 상세(사진 크게 + 정보 고정), R10 같은 글 읽기
8. 이름: "모퉁이책방", 책 표지 사진 직접 촬영 예정, 강조색 미정
9. 이메일 로그인 + 카카오, 카드 결제(PG사 연동), 재고 관리용 관리자 화면
10. 디렉션 없음 (쇼핑이 주인) · 11. 표지가 책장에 꽂혀 있다가 하나씩 앞으로 나온다 · 12. 표지 사진 촬영 예정
```

**음식점 예시 (v0.2)**
```markdown
1. 서촌 골목 2층 작은 식당. 메뉴와 분위기를 보고 자리를 예약하게 하는 사이트
2. 25~45세, 지도 앱·인스타그램을 거쳐 오는 모바일 손님 80%
3. 이번 계절 차림을 보고 자리 예약하기 (예약은 외부 예약 서비스로 연결)
4. 한 페이지: 첫 화면 / 공간 / 메뉴 / 방문 정보
5. 분위기 있는 · 따뜻한(공간) · 절제된
6. 프랜차이즈 같은 밝은 색, 음식 사진 콜라주
8. 이름 "여울 YEOUL", 사진 촬영 예정, 강조색 미정
9. 로그인·결제 없음
10. house · 11. 촛불 아래 정물이 화면 아래에서 천천히 드러난다 · 12. 사진 없음 → 렌더 시안
```

→ AI의 첫 줄 예) `preset=calm · mode=light · accent=올리브 계열(새로 들어온 책 표시에만) · 패턴: 랜딩(A형) / 목록(compare 아님, browse) / 상세(단독) / 글 / 폼(3단계) / 로그인(전용 페이지)`

→ 음식점 첫 줄 예) `preset=calm · direction=house · mode=light(+dark 섹션 1: 방문 정보) · accent=짙은 병초록(이번 계절 표시에만) · signature=정물 드러내기 · 패턴: 랜딩(D형) / 메뉴판(10) / 정보(9)`
