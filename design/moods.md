# moods.md — "이런 느낌"을 디자인 값으로 바꾸는 표

brief의 **느꼈으면 하는 단어 3개**와 **사이트 종류**로 프리셋·모드·강조색을 정한다. 결정은 결과물 맨 위에 한 줄로 적는다.
예) `preset=calm · mode=light · accent=먹빛 남색(한 가지 의미: 새로 들어온 상품 표시) — 단어: 단정한·고급스러운·따뜻한`

---

## 1단계: 프리셋 고르기 (calm / friendly)

단어 3개를 아래 표에서 찾아 점수를 더한다. 많은 쪽을 고른다. 같으면 2단계의 사이트 종류를 따른다.

| calm (차분하고 고급스러운) | friendly (산뜻하고 친근한) |
|---|---|
| 차분한 · 고급스러운 · 단정한 · 세련된 · 절제된 | 친근한 · 산뜻한 · 밝은 · 편안한 · 쉬운 |
| 진지한 · 신뢰감 있는 · 클래식한 · 우아한 | 경쾌한 · 활기찬 · 귀여운 · 따뜻한(사람) · 다정한 |
| 조용한 · 깊이 있는 · 미니멀한 · 전문적인 | 빠른 · 실용적인 · 명확한 · 상냥한 · 가벼운 |
| 따뜻한(물건·공간) · 감성적인 · 잡지 같은 | 재미있는 · 젊은 · 생기 있는 · 캐주얼한 |

- "따뜻한"은 사람·대화면 friendly, 물건·공간·소재면 calm.
- "미니멀한"만 있고 나머지가 friendly면 friendly + 장식 최소.
- "감성적인"은 **내용이 감성적**이라는 뜻으로 받는다. 장식으로 감성을 만들지 않는다 (DESIGN.md 11-2).

## 2단계: 모드 고르기 (light / dark)

| 사이트가 주로 하는 일 | 모드 |
|---|---|
| **보여준다** — 포트폴리오, 작품·사진, 초대장, 브랜드 쇼케이스, 영화·음악 | **dark** |
| **쓴다** — 예약, 쇼핑, 글 읽기, 커뮤니티, 신청·결제, 관리 도구 | **light** |
| 둘 다 (예: 쇼핑 + 브랜드 소개) | 쓰는 쪽(light) 기본, 소개 섹션 하나만 어둡게 가능 |

## 3단계: 강조색 정하기

1. 강조색의 **한 가지 의미**를 먼저 정한다: friendly면 "핵심 행동", calm이면 "하나의 상태"(새 상품, 할인, 진행 중, 현재 위치).
2. 색 방향:

| 단어 | 색 방향 (예시 범위 — 그대로 쓰지 말고 이 안에서 새로 고른다) |
|---|---|
| 신뢰·명확·전문 | 깊은 남색·청록 (명도 낮게) |
| 활기·경쾌·젊은 | 선명한 주황·초록·보라 중 하나 |
| 따뜻한·다정한 | 테라코타·살구·호박색 |
| 고급·절제·클래식 | 먹빛 남색·올리브·짙은 청록 (calm의 크림+명조와 테라코타를 함께 쓰지 않는다 — DESIGN.md 11-22) |
| 자연·편안 | 이끼·세이지 초록 |

3. 금지: 유명 서비스의 대표 색과 같거나 아주 가까운 색, 형광색, 두 가지 이상의 강조색, **주 버튼에 채도 높은 원색**(튀고 유치해 보인다 — 부품 평가).
4. `tokens.css` 아래에 사이트 파일을 하나 두고 덮어쓴다.

```css
/* app/site-theme.css */
[data-preset] { --color-accent: #…; --color-accent-ink: #…; }
[data-preset][data-mode="dark"] { --color-accent: #…(밝게); --color-accent-ink: #…(어둡게); }
```
5. `node scripts/check-contrast.mjs design/tokens.css app/site-theme.css` 통과.

## 4단계: 프리셋과 따로 고르는 것

부품 평가에서 "사이트 분위기에 따라 달라져야 한다"고 한 항목은 프리셋에 묶지 않고 사이트마다 따로 정한다. 결정 줄에 함께 적는다.

| 항목 | 고를 수 있는 값 | 기본 |
|---|---|---|
| 모서리 | 각지게(2px) / 살짝(6px) / 둥글게(10~16px) | 프리셋 값 |
| 메뉴·검색 버튼 | 아이콘 / 글자("메뉴", "검색") | 아이콘 |
| 불러오는 중 표시 | 반짝이는 자리 / 고정된 자리 / 얇은 진행 막대 | 반짝이는 자리 |
| 색 전체 | 바탕·면·글자의 온도(따뜻/차가운)까지 사이트 컨셉에 맞게 | 프리셋 값 |

모서리를 바꾸려면 `site-theme.css`에서 `--radius-*`를 덮어쓴다.

## 5단계: 세부 조절 (선택)

| 단어가 있으면 | 조절 |
|---|---|
| 잡지 같은 · 에디토리얼 | calm + 첫 화면 `display-lg`, 사진 엇갈림 섹션 1개 허용 |
| 빠른 · 실용적인 | 첫 화면 바로 검색칸 또는 목록, 히어로 이미지 생략 |
| 귀여운 | friendly + 모서리 그대로, **캐릭터·일러스트 추가 금지**(싫음 레퍼런스) — 문구 말투로만 |
| 전문적인 · 신뢰감 | 숫자·근거를 첫 화면 2등 자리에, 장식 0 |
| 미니멀한 | 섹션 수 최소, 질감(`bg-texture`) 쓰지 않음 |
| 세련된·깔끔한이 **아주 강함** + 보여줄 내용물이 있음 | 첫 화면 **무대형(patterns 1장 C형)**: 내용물이 화면 전부, 글은 구석 표 + 이름표 한 줄, 설명은 메뉴로 (R19, 2026-10-28 사용자 확정) |
| 따뜻한(공간) | calm 크림 바탕 그대로, 사진은 자연광 톤 |

## 확인한 조합 (취향 프로필 근거)

| 조합 | 근거 |
|---|---|
| calm · light | 크림 바탕 패션 홈, 패션 상세 (좋음) |
| calm · dark | 포트폴리오 탐색, 모바일 초대장 (좋음) |
| friendly · light | 서비스 랜딩·가입·결제, 기술 블로그 글, 쇼핑 목록 (좋음) |
| friendly · dark | 모바일 목록·작업 모음 (좋음, 단 무늬 배경 위 대비 흠) |
