# directions.md — 아트 디렉션 (v0.2)

> 프리셋(calm/friendly)은 **쓰는 사이트의 바탕**이고, 디렉션은 **보여주는 사이트의 얼굴**이다.
> 디렉션 하나를 고르면 글꼴 짝 · 색 · 모서리 · 선 · 배치 문법 · 움직임 단계 · 시그니처 자리가 한 번에 정해진다.
> 값은 `tokens.css`의 `[data-direction="…"]`, 글자 규칙은 `typography.md`, 완성본 예시는 `../examples/`.
>
> 각 디렉션은 레퍼런스에서 **원리만** 뽑았다. 레퍼런스의 색·글꼴·이미지·문구·시그니처 연출은 가져오지 않았다 (DESIGN.md 12장).

```html
<html lang="ko" data-preset="calm" data-direction="house" data-mode="light">
  …
  <section data-mode="dark">어두운 섹션은 하나만</section>
</html>
```

---

## 0. 고르는 법

| brief에 이런 말이 있으면 | 디렉션 | 바탕 프리셋 |
|---|---|---|
| 분위기 있는 · 고급스러운 · 따뜻한(공간) · 감성적인 · 공간/브랜드/식당/호텔/패션 | **house** | calm |
| 잡지 같은 · 영화 같은 · 작품 · 크레딧 · 아카이브 · 포트폴리오 · 출판 · 정확한·전문적인 + 보여줄 모형·도면 | **editorial** | calm |
| 만져보는 · 직접 고르는 · 제품 하나 · 꾸미기 · 체험 · 3D | **object** | friendly |
| 예약·쇼핑·글·도구가 주인 (보여주기는 곁들임) | 디렉션 없음 → 프리셋만 | calm/friendly |

- 디렉션은 **하나만**. 섞지 않는다.
- 쓰는 기능(예약 폼·결제·마이페이지)은 디렉션이 있어도 기존 부품 규칙을 그대로 따른다. 디렉션은 "얼굴"(첫 화면·소개·목록의 보여주는 부분)에만 쓴다.
- 결정 줄에 함께 적는다: `preset=calm · direction=house · mode=light(+dark 섹션 1) · accent=…(한 가지 의미) · signature=…`

## 1. house — 하우스 브랜드형

**쓰는 곳**: 음식점, 카페·바, 호텔·스테이, 패션·잡화 브랜드, 향·공예 브랜드
**배운 원리**: 큰 사진·영상이 화면을 채우고, 글자는 작고 조용하게 가장자리에 붙는다. 장식은 선 1px과 여백뿐.

| 항목 | 값 |
|---|---|
| 바탕 | 따뜻한 상아(`bg #f1ebe1`) + 어두운 섹션 1개(`#16110d`, 촛불 아래 테이블 같은 갈색 먹) |
| 글꼴 | 워드마크·큰 숫자 = Cormorant Garamond / 한글 제목 = Noto Serif KR / 영문 라벨 = Inter Tight 대문자 / 본문 = Pretendard |
| 크기 대비 | `micro-label`(11) ↔ `display-xl`(44→104). 중간 크기(20~28)는 아껴 쓴다 |
| 모서리 | 0. 작은 토글·칩만 알약 |
| 선·그림자 | 1px 선(`line`)으로만 나눈다. 카드 그림자 없음 |
| 강조색 | 짙은 병초록 — 한 가지 의미 **"이번 계절"** 표시에만 |
| 주 버튼 | 진한 먹색 바탕, 대문자 라벨이 아니라 한글 1~3단어 ("자리 예약하기"), 크기는 기본(md) — 첫 화면에서도 lg를 쓰지 않는다 |

**배치 문법**
1. 첫 화면 = `FullBleedMedia` (사진/영상이 화면의 88% 이상, patterns 1장 D형). 글자는 왼쪽 아래에 모은다: 라벨 → 큰 한 줄 → 사실 한 줄(위치·시간) → 주 행동.
2. 헤더는 투명, 워드마크 가운데 또는 왼쪽, 메뉴는 `micro-label` 크기의 글자. 내려가면 상아 바탕 + 아래 선.
3. 소개 = `EditorialSplit` (사진 4/5 반 + 글 반). 글 쪽은 라벨 → 제목(title-lg 명조) → 문단 2개 이하 → `SpecList align="start"`.
4. 목록 = 글자 목록(`MenuList`, `IndexList`) 우선. 사진은 `DragGallery` 한 줄로 따로 모은다 (사진과 글을 한 카드에 같이 넣지 않는다).
5. 어두운 섹션은 하나: 방문 정보나 영상 한 장.

**시그니처 자리 (1개만, 사이트마다 새로 정한다)**
- 예) 음식점: "정물 사진이 화면 아래에서 천천히 드러난다(reveal)" / 향 브랜드: "병 하나가 화면 중앙에서 회전" / 호텔: "객실 번호가 큰 세리프 숫자로 목록이 된다"
- 레퍼런스의 장치(예: 특정 사이트의 무늬 테두리, 마스코트)를 옮기지 않는다.

**하지 않을 것**: 크림+명조+테라코타 조합, 모든 섹션 가운데 정렬, 사진 위에 긴 문단, 금색 장식선, 손글씨 글꼴

## 2. editorial — 에디토리얼 크레딧형

**쓰는 곳**: 영화·전시·공연, 출판·잡지, 사진가·감독 포트폴리오, 아카이브
**배운 원리**: 작품 자체가 "물건"처럼 화면에 놓이고, 정보는 영화 크레딧처럼 라벨-값 목록으로 정리된다.

| 항목 | 값 |
|---|---|
| 바탕 | 밝은 무채색(`#ededeb`). 어두운 모드는 상영·관람 페이지에서만 |
| 글꼴 | 제목·인용 = Instrument Serif (한글은 Noto Serif KR) / 라벨 = Inter Tight 대문자 / 본문 = Pretendard |
| 크기 대비 | `micro-label`(11) ↔ `display-lg`·`display-xl`. 인용문은 대문자 세리프 `title`~`display-sm` |
| 모서리·그림자 | 0 · 없음. 작품 이미지에만 아주 옅은 그림자 허용(물건처럼 보이게) |
| 강조색 | 먹빛 청색 — 한 가지 의미 **"지금 상영·진행 중"** |

**배치 문법**
1. 왼쪽 위에 `SpecList`(감독·연도·출연처럼 라벨 왼쪽, 값 오른쪽, 1px 선)를 작게 둔다. 화면의 나머지는 작품. (patterns 1장 C형 무대형과 같은 원리)
2. 작품 목록은 같은 크기 오브젝트의 줄(`DragGallery`). 선택된 하나만 크게 — 다른 것은 작게·흐리게.
3. 평가·인용은 `PressQuote`(별점 + 매체명 라벨 + 대문자 세리프 인용). **실제 출처가 있는 인용만.**
4. 메뉴는 가운데 위 글자 3개 이하, 현재 항목 아래 점 하나.

**시그니처 자리**: 작품을 어떤 "물건"으로 보여줄지 하나 정한다 — 예) 책이면 펼쳐진 책등, 전시면 액자 그림자, 사진집이면 인화지 가장자리. 레퍼런스의 물건(예: 원판 디스크를 호 모양으로 늘어놓기)을 쓰지 않는다.

**하지 않을 것**: 작품 위 큰 글자 덮기, 라벨을 한글 11px로 쓰기, 인용 3개 이상 나열, 별점 장식 남발

## 3. object — 오브젝트 쇼케이스형

**쓰는 곳**: 제품 하나를 꾸미기·고르기(커스터마이저), 3D 제품 소개, 체험형 캠페인, 비트 메이커 같은 도구의 첫 화면
**배운 원리**: 화면 가운데 주인공 오브젝트 하나, 조작은 가장자리에 떠 있는 작은 둥근 버튼, 행동은 오른쪽 아래 버튼 하나로 끝낸다.

| 항목 | 값 |
|---|---|
| 바탕 | 차가운 옅은 면(`#e6eaed`) + 오브젝트 아래 옅은 바닥 그림자 |
| 글꼴 | 모두 Inter Tight / Pretendard. 세리프 없음 |
| 모서리 | 알약(컨트롤), 24(카드·창) |
| 그림자 | 떠 있는 컨트롤에만 `raised` |
| 강조색 | 짙은 청록 — 한 가지 의미 **"핵심 행동(완성·제출)"**. 원색 금지 |

**배치 문법** (`ObjectStage`)
1. 가운데: 오브젝트(three.js 캔버스, 렌더 이미지, 또는 실물 사진). 화면 높이의 70% 이상.
2. 위 가운데: 모드 전환 알약 토글 하나(예: 만들기 / 모아보기).
3. 오른쪽 가장자리: 세로로 쌓인 원형 도구 버튼 4개 이하 + 선택된 도구의 옵션(색 점 등).
4. 왼쪽 위: 뒤로 가기 + 이름. 오른쪽 아래: 주 행동 하나. 왼쪽 아래: 언어·약관 같은 작은 글자.

**시그니처 자리**: 오브젝트와 상호작용하는 방식 하나 — 예) 끌어서 돌리기, 칠하기, 소리에 맞춰 흔들리기.

**하지 않을 것**: 오브젝트 주변에 설명 문단, 도구 5개 이상, 배경 무늬가 오브젝트보다 눈에 띄기, 끌어야만 볼 수 있는 핵심 정보

## 4. 새 디렉션을 추가할 때

1. 레퍼런스 2개 이상에서 **같은 원리**가 보일 때만 만든다 (하나만 보고 만들면 복제가 된다).
2. 위 표의 항목을 모두 채운다: 쓰는 곳 · 배운 원리 · 값 · 배치 문법 · 시그니처 자리 · 하지 않을 것.
3. `tokens.css`에 `[data-direction="이름"]` 블록 → `npm run contrast` 통과.
4. `examples/`에 완성본 예시 페이지 1개를 만든다. **예시 페이지가 없는 디렉션은 "시험 중"으로 표시한다.**

| 디렉션 | 상태 | 완성본 예시 |
|---|---|---|
| house | 예시 있음 | `examples/house-restaurant/` |
| editorial | 첫 적용: Auto-BIM(floor-plan) — 무대형 첫 화면(patterns C형)과 함께 | 사이트 저장소의 화면 캡처 |
| object | 시험 중 (값 + `ObjectStage` 틀) — patterns C형 무대형이 이 디렉션의 첫 화면 | — 비트 메이커 첫 화면으로 만든다 |
